# Security Policy

## Supported version

Security fixes target the latest release on the default branch.

## Reporting

Please report vulnerabilities privately to the repository owner. Do not attach real prompts, transcripts, hook payloads, configuration files, API keys, account identifiers, or `%LOCALAPPDATA%\AIOfficeDollhouse` event files to a public issue.

Include a minimal synthetic reproduction, affected version, and expected impact. The project is observational only; behavior that controls an external AI process or captures task content is out of scope by design and should be treated as a security defect.
