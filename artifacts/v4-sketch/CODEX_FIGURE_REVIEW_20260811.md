## 第一輪：Codex 抓到、我沒看到的問題（全部已修）

1. `renderer.js` 的 `poseFor()` 用 `placement.facing` 覆蓋掉 `travelPose()` 的朝向 → 走路的人朝向錯誤。
2. 搬運姿勢肘角 148/122 度，手臂沒有真的環抱箱子。
3. `lean` 時肩線移動但手臂根仍固定在 ±1.8 → 肩接點錯位。
4. 身分色四家相對亮度 .1386-.2726（1.97 倍差）。**我用 node 自行複算確認屬實**，
   改為 Codex 提案的四色，亮度收斂到 .1576-.1740（1.10 倍差）。
5. 色條含圓帽實際長 3.7px 且離腳線過近 → 端點改 ±1.15、y 下移。
6. 我的新測試過度約束（頭半徑釘死 1.25、線寬集合釘死、全域禁 88-92 度）→ 已放寬成
   逐姿勢區間（站/走膝 163-177、坐膝 92-108、肘 80-172），並把肩線排除在關節判定外。

## 第二輪：兩個爭點

**椅背位置**：Codex 第一輪要求座後端 -1.1 / 椅背端 -1.25。我指出那會讓椅背穿過軀幹
（肩端在 -1.8），且違反它自己規格 §1 的「離背部至少 0.8px」。
**第二輪 Codex 同意撤回**，確認以「坐姿可見後緣」為基準，維持座墊 1.6→-2.5、椅背端 -2.7。

**坐姿遠臂**：Codex 兩輪都要求遠臂不得跨過脊椎，第二輪給了遠手 (-0.6,-4.45)。
我實際渲染後**不採用它的數值**：那組座標會讓遠臂的肘落在 x≈-2.55，**撞上椅背**，
正是 D1 第 5 點要清除的重疊（證據圖 `figure-sit-far-arm-codex-proposal-20260811.png`）。
另試「手停在脊椎線上」也只是把封閉三角換成封閉方框。
**最終採第三種解法：坐姿是四分之三視角，遠臂被軀幹遮住，不畫。**
同時滿足「不跨脊椎」與「不撞椅背」，且 13px 下讀起來就是側身坐著。

## 第二輪 Codex 提出、我未採納的三點（附理由）

- **頸隙 .95 → .50**：與它第一輪「.95 可接受、不可再縮」的裁決自相矛盾。實圖上縮到 .5
  會讓實心頭與肩線黏成一坨（這正是改前最醜的成因之一）。維持 .95。
- **色條再下移到 y=1.75**：目前 y=1.35，墨跡間距 0.6px，實圖已清楚分離；再下移會讓
  色條與人偶脫離關係。維持 1.35。
- **`drawPlanFigure` 補測 r=2.5 與 alpha .55**：測到「整盤上身分色」已足夠釘住設計意圖，
  半徑與透明度屬可調參數，釘死會變成第二次過度約束。
