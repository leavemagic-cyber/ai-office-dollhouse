紙片樓板在深色桌布上靠自身米白底＋落影維持可讀；淺色桌布上靠石墨線。不搶焦點、樓板外點擊穿透。

3. 任務 → 樓層插入・線稿畫出動畫

① 線稿畫出
② 樓層插入
③ 內裝逐筆完成
④ 開工常駐

動畫預算：畫出 ≈0.8s（stroke 進度）、插入位移 ≈0.4s ease-out、人偶進場 0.3s；全部單 canvas 可做、閒置零動畫。任務結束 = 內裝淡出 → 樓板線稿「擦除」→ 其餘樓板合攏。第 ① 格為循環示意動畫。

4. 微型積木人偶（7% 尺度）

  • 7% 尺度下人偶簡化為 4 件積木：倒角方頭（無臉）＋淡彩軀幹（provider 色 75%）＋雙腿石墨色；輪廓 0.4px 石墨線。
  • 放大模式（使用者把視窗拉寬）才切換到 28px 細節版：2×2 點眼、楔形手、四材質家族——沿用既有 IP 審查通過的設計語彙。
  • IP 檢核不變：無凸粒、無 C 型手、無圓柱頭、非亮黃膚色、無品牌色/Logo、無外部素材；純線稿與淡彩皆為原創繪製。
  • 真實性不變：人偶數＝真實 session/事件，不虛構人員。
